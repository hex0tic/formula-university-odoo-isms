# Бие даалтын удирдлага

Энд шаардлага, кейс, бүтцийн төлөвлөгөө, агентын харилцаа, хичээлийн судалгаа, ажлын хуваарилалт, шийдвэр ба нотолгооны индекс хадгалагдана.

| Файл | Зориулалт |
|---|---|
| messages.md / worklog.md | Агент хоорондын харилцаа / бодит ажлын бүртгэл; append-only |
| requirements.md / acceptance.md | Албан заавар ба хүлээн авах нотолгоо |
| case.md / architecture.md | Их сургуулийн шинэ кейс ба системийн бүтэц |
| implementation-plan.md / decisions.md | Дараалал, dependency, тогтсон шийдвэр |
| assignments.md / coordination.md | Агентын эзэмшил ба хамтран ажиллах журам |
| human-responsibilities.md / team.md | Хэрэглэгчийн баталсан5 хүний үүрэг, өмнөх тайлангаас авсан нэр |
| course-review.md / glossary.md | Лекц, семинарын source map ба нэр томьёо |
| environment-audit.md | VM registry/reuse ба runtime сонголт |
| odoo-guide.md / operations.md | Odoo-ийн зорилго, бүтэц, ажиллуулах ба шалгах заавар |
| schema-university_isms.md / soa-qa.md | Canonical data гэрээ ба хэрэгжилтийн factual QA |

Эцсийн тайлан, слайд, 12 минутын demo script нь `../reports/`-д. Код `../odoo/addons/`, өгөгдөл `../data/`, бодлого `../policies/`, бодит нотолгоо `../evidence/` дотор байна. Кейсийн өгөгдөл зохиомол; системийн тест ба зургууд нь ажилласан орчноос гарсан. Нууц файлууд source archive-д ороогүй.
