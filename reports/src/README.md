# Тайланг дахин үүсгэх

ReportLab, Pillow болон Liberation Serif фонтоор PDF үүсгэнэ. `python3 reports/src/build_report.py` ажиллуулна. Canonical data, screenshot-уудыг үндсэн хавтаснаас уншина. Шинэ агуулга бүрийн дараа PDF-ийн TOC холбоос, bookmarks, хуудас, зураг, хүснэгтийн layout-ийг render хийж шалгана. PowerPoint нь native text/table-тай тул шууд засварлаж болно.
