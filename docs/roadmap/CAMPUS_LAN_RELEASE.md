# Formula University: портал ба элсэлтийн шинэчлэл

Сургуулийн веб, оюутны портал, багшийн веб, элсэлтийн өргөдөл нэг Odoo өгөгдлийн сан ашиглана. Staging-ийн жишээ өгөгдлийг үндсэн LAN орчинд импортлохгүй.

| Хэсэг | Хаягийн зам | Хэн ашиглах вэ |
|--|--|--|
| Нийтийн веб | `/university` | Зочин |
| Элсэх өргөдөл | `/university/admissions/apply` | Өргөдөл гаргагч |
| Өргөдлийн төлөв | `/university/admissions/status` | Өргөдлийн дугаар, кодтой хүн |
| Элсэх өргөдлийн жагсаалт | **Formula Campus → Элсэх өргөдөл** | Сургалтын алба |
| Оюутны портал | `/my/campus` | Оюутан |
| Багшийн веб | `/campus/teacher` | Багш |
| Зөрчил мэдээлэх | `/my/campus/incidents` | Оюутан, багш |

Сургалтын алба өргөдлийг хянаж батлахад оюутны код, сургалтын бүртгэл болон Portal төрлийн бүртгэл үүснэ. Татгалзах үед тайлбар шаардлагатай. Төлөв шалгах хуудас зөвхөн өргөдөлд зориулсан шийдвэрийн тайлбарыг харуулна. Порталын анхны урилгыг SMTP тохируулсны дараа сургалтын алба илгээнэ. Үүсээд байсан хэрэглэгчийг цахим шуудангаар нь автоматаар холбохгүй.

Нийтийн каталогт гарсан хөтөлбөрийг үндсэн академик хөтөлбөртэй системийн админ холбоно. Зөвхөн нийтэлсэн бөгөөд идэвхтэй академик хөтөлбөртэй холбогдсон нэр дээр өргөдөл авна.

Багш веб дээр өөрийн хариуцсан хичээл, оюутны жагсаалт, ирц, дүн өөрчлөх хүсэлтээ удирдана. Дүнгийн хүсэлт илгээх нь дүн өөрөө өөрчлөгдсөн гэсэн үг биш; сургалтын алба өмнөх журмаар батална. Ажилтны чат болон ISMS дотоод эрх тусдаа хэвээр байна.

LAN хувилбар нь үндсэн өгөгдлийн сангийн хуулбар дээр шалгагдсан addon багцыг ашиглана. Суулгасан нэмэлт модулиуд: `campus_academic_plus`, `campus_portal`, `formula_campus_web`, `formula_design_system`. Одоо байгаа `campus_university`, `campus_isms_bridge`, `university_isms_helpdesk` модулиуд шинэчлэгдсэн. Cutover хийхдээ өгөгдлийн сан, хавсралт, addon модыг нэрлэсэн хувийн нөөцөд авч шалгана.

2026 оны 11-р сарын 27-нд үндсэн LAN дээр суулгасан. Нийтийн веб: `https://192.168.1.22:8443/university`. HTTPS сертификатыг сургалтын LAN CA-аар баталгаажуулсан. Өмнөх оюутан ба багшийн бүртгэлээр нэвтэрч шалгасан. Өмнөх оюутны бүртгэл, дүн, зөрчил, аудитын түүх болон хавсралтын бүртгэлүүд хэвээр. Шинэ 12 автомат тест тэнцсэн. Хуулбар орчинд элсэлт батлах, анги тусгаарлах, ирц, дүнгийн хүсэлт, зөрчил хүлээн авах урсгалыг браузераар туршсан.

LAN дээр Кибер аюулгүй байдлын нийтлэл `SEC` академик хөтөлбөртэй холбогдсон. Бусад нийтлэлээс өргөдөл авахын өмнө Оdoo-д харгалзах хөтөлбөр бүртгэж холбоно. Үндсэн орчинд SMTP сервер тохируулаагүй тул шийдвэрийг веб дээр кодоор шалгана; шинэ бүртгэлийн урилга илгээхэд SMTP тохируулна.

2026 оны 11-р сарын 27-ны ажиллагааны тохиргоо:

- `2026-A` намрын улиралд `ORG-338`, `ORG-342` хичээлийг холбов. Хичээл сонголт 11-р сарын 30-ныг дуустал, нэмэх, хасах хугацаа 12-р сарын 2-ныг дуустал. `ORG-342`-ын жишиг хуваарь 11-р сарын 27-ноос 12-р сарын 23 хүртэл 8 цагтай. `ORG-338` хаалттай хэвээр бөгөөд түүнд хуваарь зохиож оруулаагүй.
- Кибер аюулгүй байдлын элсэлт нээлттэй. Бизнесийн аналитик, дижитал дизайн каталогт харагдах бөгөөд «Элсэлт нээгдээгүй» гэсэн тайлбар гарна. Тухайн хөтөлбөрийн дэлгэрэнгүйд өргөдлийн товчийн оронд лавлагааны холбоос байна.
- Оюутны урилга үүсэхэд HTTPS LAN хаяг ашиглагдахаар Odoo-ийн үндсэн хаягийг тогтоосон. SMTP сервер хараахан байхгүй тул бодит урилга илгээгээгүй. Сервер бэлэн болсны дараа админ гадагш илгээх серверийн холболтыг шалгаж, сургалтын алба батлагдсан өргөдлөөс туршилтын урилга илгээн анхны нэвтрэлтийг шалгана.
- Үндсэн өгөгдлийн сан, файлын санг Улаанбаатарын цагаар өдөр бүр 04:30-д шифрлэж нөөцөлнө. Сар бүрийн эхний нямд 05:30-д тусдаа өгөгдлийн санд сэргээн шалгана. Эхний сэргээх туршилтаар 192 хавсаргасан файл таарч, сэргээх, шалгах ажил 53 секунд үргэлжилсэн. Нөөц тухайн компьютерт хадгалагдана. Тусдаа төхөөрөмж рүү хуулбарлах тохиргоо хийгдээгүй.
