## MFA-г багийн бүртгэлд идэвхжүүлэх

1. Хэрэглэгч өөрийн бүртгэлээр орж **Хувийн тохиргоо → Account Security → Two-Factor Authentication** хэсгийг нээнэ. Өөрийн authenticator апп дээр QR уншуулж, дэлгэцийн кодоор баталгаажуулна.
2. Тусдаа цонхонд дахин нэвтэрч код асууж байгааг шалгана. QR, нууц түлхүүр, кодыг чат, тайлан, репод хадгалахгүй. Төхөөрөмж алдагдсан үед админ хэн болохыг шалгаад TOTP-г дахин бүртгүүлэх урсгалыг хэрэглэнэ.
3. Хамрагдах бүртгэл тус бүрийн нэвтрэлт батлагдсаны дараа системийн админ `university_mfa_policy.enforce_date`-г `YYYY-MM-DD` хэлбэрээр тохируулна. Энэ параметр өндөр нөлөөтэй үйлдэлд TOTP бүртгэл шаардана. Odoo-ийн нэвтрэх дэлгэц бүртгүүлсэн хэрэглэгчээс код нэхнэ; тухайн үйлдэл бүр дээр шинэ код нэхэхгүй.

## Гаднах нөөцийг ажилд оруулах

1. Үндсэн төхөөрөмжөөс тусдаа байршлын зөвшөөрөгдсөн диск, NAS эсвэл SSH хост сонгоно. Диск эсвэл NAS бол `ISMS_BACKUP_COPY_DIRS`-д шууд mountpoint тохируулна. SSH бол `ISMS_BACKUP_RSYNC_TARGET`, түлхүүрт нэвтрэлт, баталгаажуулсан host key болон `rsync` хэрэгтэй.
2. Шифрлэлтийн түлхүүрийн сэргээх хуулбарыг архивтай нэг байршил, нэг эрхээр хадгалахгүй. Гаднах хадгалалтад нөөцийн файл болон manifest л очно.
3. Тухайн хадгалалтаас `restore_verify.sh`-аар шинэ түр санд сэргээнэ. Нөөцийн нас, сэргээх хугацаа, хэш, өгөгдөл ба хавсралт таарвал шалгалтыг хаана. Энгийн локал хавтсанд үүсгэсэн хуулбарыг offsite гэж бүртгэхгүй.
