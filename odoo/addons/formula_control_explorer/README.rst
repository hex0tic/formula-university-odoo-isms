================================
Formula ISO Control Explorer
================================

Annex A (ISO/IEC 27001:2022) 93 хяналтын каталог, Statement of Applicability (SoA)
дэлгэрэнгүй, холбоотой эрсдэл / хөрөнгө / бодлого / инцидент, нотолгоо, тооцсон шалгалт.

Суурилуулалт
------------

* Хамаарал: ``web``, ``university_isms``.
* Цэс: ISMS → Хяналт ба SoA → **Control Explorer**.
  Харагдах эрх: ``group_isms_asset_owner`` эсвэл ``group_isms_auditor`` (цэсийн эцэг цэстэй ижил).

Эрхийн загвар
-------------

* Бүх өгөгдөл хэрэглэгчийн ORM эрхээр уншигдана. ``sudo()`` нь өгөгдөл уншихад ашиглагдахгүй.
* ``isms.control`` ACL: reporter / asset owner / analyst / auditor уншина; засах боломж нь
  стандарт «Хяналт» маягтаар л (analyst, manager).
* Холбоос (эрсдэл, хөрөнгө, бодлого, инцидент) зөвхөн хэрэглэгч уншиж чадах бичлэгийг агуулна.
  Уншиж чадахгүй бичлэг нь жагсаалтад орохгүй, тоонд ч оруулахгүй.
* ``isms.control`` дээрх ``justification``, ``evidence``, ``odoo_implementation``, ``risk_ids``,
  ``asset_ids`` талбарын ``groups`` нь ORM-ийн талбарын эрхээр шалгагдана; таны эрх хүрэхгүй
  бол «харах эрх байхгүй» гэж харагдана.
* Нэг exception: «холбоос бий эсэх» гэсэн boolean-ийг ``sudo()``-оор шалгаж, «эрсдэлгүй» гэж буруу
  дүгнэхээс сэргийлнэ (``_forward_links``). ID эсвэл тоо гаргахгүй. Бодлогын шалгалтад хэрэглэх
  эсэхийг policy-ийн хүрээнд дахин хянах шаардлагатай.

Тооцсон шалгалтууд (findings)
-----------------------------

Төлөв: ``gap`` (саад), ``ok`` (зөв), ``na`` (хамаарахгүй), ``not_evaluated`` (таны эрхээр шалгах
боломжгүй). Энэ нь системийн өгөгдөл дээр тооцсон автомат шалгалт бөгөөд аудитын дүгнэлт биш.

Дахин хянах огноо
-----------------

Хяналтын бүртгэлд дахин хянах огноо байхгүй. Холбоотой бодлогын ``next_review_date``-ийг
уншиж чадах хэсгээр харуулна. Огноо зохиож бичигдэхгүй.

Тест
----

::

    MODULES=formula_control_explorer TAGS=/formula_control_explorer <тест ажиллуулах скрипт>

* ``tests/test_control_explorer.py``: каталогийн тоо, шүүлтүүрийн ORM домайн, холбоосын эрх,
  role parity, тооцсон шалгалт.
* ``tests/test_assets_compile.py``: ``web.assets_backend``-ийн SCSS компайл, Owl JS transpile,
  XML template parse. SCSS алдаа гарвал тест унана.

Хязгаарлалт
-----------

* Owl UI, responsive (360 / 768 / 1440) болон keyboard үйлдлийг браузерээр баталгаажуулаагүй.
* Жагсаалт нь нэг дуудлагад дээд тал нь 200 мөр; 93 хяналтад хангалттай.
