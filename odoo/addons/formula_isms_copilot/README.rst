Formula ISMS туслах (formula_isms_copilot)
=========================================

Phase 7 (AI-01..AI-05). Зөвхөн унших, эрхэд суурилсан ISMS туслах.

* Хайлт: бодлого, Annex A хяналт (SoA), эрсдэл, хөрөнгө, инцидент, олдвор, нотолгоо, аудит лог.
  Бүх уншилт хэрэглэгчийн ORM эрхээр (ACL, record rule, field groups); sudo() ашиглахгүй.
* Хөдөлгүүр: анхдагч нь дотоод, детерминистик, сүлжээ ашиглахгүй хураангуй. Гадаад LLM провайдер
  анхдагчаар унтраалттай; идэвхжүүлэхэд админ тохиргоо, өгөгдлийн бодлогын зөвшөөрөл, PII маскчилт шаардлагатай.
* Санал (AI-03): эрсдэл -> Annex A хяналт, инцидент -> хураангуй, хяналт -> дутуу нотолгоо.
* Туслах руу бичих метод байхгүй. Approve, close, grant, accept, delete, дүн өөрчлөх хүсэлтэд татгалзана.
* Асуулт, санал бүр formula.copilot.query.log-д бүртгэгдэнэ (хариултын текстгүй); уншихыг аудитор/CISO хийнэ.

Тохиргоо: Settings > ISMS туслах (base.group_system).
Тест: tags ``formula_isms_copilot``. Гадаад HTTP дуудлага бүх тестэд mock хийгдэнэ.
